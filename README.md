# Family tree

Open `index.html` in a browser. No install, no server needed.

## Files
- `family-data.js`  – the people (the only file your mom needs to edit)
- `photos/`         – put pictures here, ~400x400 px, then write e.g. photo: "photos/anna.jpg"
- `index.html`      – page skeleton
- `style.css`       – all the looks (colours are at the top)
- `app.js`          – builds the tree from the data (read the comments, they compare JS to Python)

## Known limits (good next steps)
- One spouse per person (no remarriages / half-siblings yet)
- The tree grows downward from one root couple
- No in-browser editor yet; edit family-data.js
